# Wildlife artwork credits

The silhouettes in this folder are used as single-colour CSS masks on the site (see `assets/js/nature.js`,
`assets/css/wild.css`, `assets/css/site.css`). Some files were modified: the black background square was removed
from the game-icons files, and XML headers/comments were stripped from the Noto files.
