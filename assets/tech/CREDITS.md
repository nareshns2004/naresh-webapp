# Technology icon credits

Every icon in this folder was drawn for this site (generated as plain SVG paths: vacuum tube, transistor, logic gates, shield, key, fingerprint, firewall, blockchain, browser, chat, DNA, rocket, fusion, brain–computer interface,
DIP and CPU packages, wafer, punch card, tape, floppy, hard disk, CRT, network mesh, Ethernet jack, switch, NIC, server
rack, cloud, GPU, neural network, attention matrix, robot, atom, Bloch-sphere qubit, quantum chip, dilution
refrigerator, photonics and more). They are single-colour and used as CSS masks by `assets/js/era.js`,
`assets/css/era.css`, `assets/css/site.css` and the footer timeline in `assets/js/site.js`. No third-party artwork.
The skylines and interlude cutaways are generated in `assets/js/era.js`. Emoji render in the visitor's system font.
